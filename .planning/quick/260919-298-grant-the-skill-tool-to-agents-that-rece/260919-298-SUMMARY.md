## Deviations from Plan

**1. [Rule 1 - Bug] Task 1 verify string false negative from grep exit-status propagation**
- **Found during:** Task 1 verification
- **Issue:** The plan's Task 1 automated verify ends with `bad=$(... | grep -vE '...') && [ -z "$bad" ] && echo GRANT-OK`. A `var=$(pipeline)` assignment takes the exit status of the pipeline's last command; the trailing `grep -v` exits 1 when it correctly finds no offending lines (the success case), so the `&&` chain short-circuits and GRANT-OK is never printed despite all conditions passing.
- **Fix:** Re-ran the identical checks with the `bad=` assignment's exit status decoupled (appended `; true`) and per-check `|| exit 1` guards. All semantic conditions passed and GRANT-OK printed. No change to the agent files; this is a verify-harness observation only.
- **Files modified:** none (verification harness only)
