# Quick 260920-r94: Per-language import-habit drift axis Summary

Four regex-reliable import-habit dimensions (`py-wildcard-import`, `py-import-relativity`, `rust-glob-import`, `go-import-ordering`) now vote and flag through the existing majority-vote / entropy / dominance machinery in `bin/lib/conventions.cjs`, with the CLI corpus glob widened to feed .go/.py/.rs files to the engine.

## What was built

- Registered the 4 new axes in `AXES` and generalized both `observeFile` obs and `deriveConventions` tallies init to `Object.fromEntries(AXES.map((a) => [a, {}]))`, removing the two hardcoded 4-key literals.
- Added line-anchored, comment-stripping detectors (`pyWildcardVariant`, `pyRelativityVariant`, `rustGlobVariant`, `goOrderingVariant`), each returning `{ variant, line } | null` (null abstains), plus a `stripSlashComments` helper for the Go/Rust packs. Rust detection applies the `super::*`/`self::*` skip and the trailing `#[cfg(test)] mod` truncation guard.
- Wired a frozen `LANG_AXES` extension dispatch and a `LANG_AXIS_FIX` hint table (`langAxisFix`). `observeFile` and `checkConformance` both dispatch by `path.extname`; the conformance dispatch runs before the JS/TS `continue` so .py/.rs/.go files are checked, and only NAMED axes flag (contested/insufficient-data flag nothing).
- Gated the legacy JS/TS export-style + import-style observation block in `observeFile` behind `JS_TS_RE.test(file)`, mirroring the conformance-side gate, so Go `import ( ... )` blocks and Python `import`/`from ... import` lines cast zero legacy cjs/esm votes once SRC_RE is widened.
- Widened `collectConventionCorpus` `SRC_RE` in `bin/lib/verify.cjs` to `/\.(c|m)?[jt]sx?$|\.(go|py|rs)$/`.
- Exported the 4 detectors for direct unit tests; added a full regression section to `tests/conventions.test.cjs` and updated the axis-name deepStrictEqual to the 8-name list.

## Deviations from Plan

None. Plan executed exactly as written (Task 1 step 4a JS_TS_RE gate applied to both legacy axes as specified).

## Deferred (not built, per plan)

- Rust intra-crate path style (`crate::` vs `super::`/`self::`) - both valid, noisy.
- Rust use-grouping (`use a::{b, c};` vs separate lines) - needs cross-line prefix reconstruction.
- Go 3-way stdlib/third-party/local grouping - needs the go.mod module path (parser/config work).
