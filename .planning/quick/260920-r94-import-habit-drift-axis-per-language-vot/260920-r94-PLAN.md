regex-reliable dimensions (`py-wildcard-import`, `py-import-relativity`,
`rust-glob-import`, `go-import-ordering`) that vote and flag through the existing
majority-vote / entropy / dominance machinery in `bin/lib/conventions.cjs`, plus the

Purpose: today the only import-habit signal is JS/TS cjs-vs-esm. Go/Python/Rust files
participate in file-name casing but carry no import-habit vote, so a repo with a clear
habit (sorted Go imports, absolute Python imports, explicit Rust `use`) never gets an
advisory when a change breaks it. This is the first cut of the VibeDrift import-habit
port, scoped to what regex can detect without a parser.

tests for every dimension and guard, regenerated `dist/bm` copies, all gates green with
