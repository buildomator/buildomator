<objective>
Build the mechanical core of the Decision Reconciliation Guard in both twins: read the
STATE.md decision log, retrieve same-topic candidate rules from the project authority docs
with no model call, keep a content-hash ledger of per-decision outcomes, keep a
merge-preserving pending-conflict record shared by both firing points, and gate which docs
may be auto-rewritten. Also write the agent-procedure reference doc that the two firing-point
plans point at, so the directive, the judgment contract, and the uniform ask path exist before
either firing point is wired.

Purpose: every other plan depends on this engine and this contract. Delivers the
no-model-when-no-candidate rule (RECON-04), the ledger (RECON-05), and the safety allowlist
(RECON-06). The semantic judgment itself is agent-driven and not part of this plan.

Output: `reconcile` query command in both twins, the ledger format, the pending-record
format, the safety gate, the agent-procedure reference, and unit + parity tests over three
golden fixtures.
</objective>
