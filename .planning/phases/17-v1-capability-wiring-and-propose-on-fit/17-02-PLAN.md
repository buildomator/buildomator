- without `--approved` and no prior approval: returns `{ inserted:false, needs_approval:true, verdict, prompt }` and writes nothing
- refuses only `verdict === 'block'`; a `flag` verdict is accepted when approved (so the autonomous gate must check `allow` itself)
- `--location` is a project-relative dir containing SKILL.md, or `global:<name>` resolving to `<runtime skills dir>/<name>/SKILL.md`; frontmatter `name` must equal the catalog `skill_name`; a git checkout must be at `pinned_commit` (a non-git dir is accepted with `pin_verified:false`)
- success: `{ inserted:true, id, agent, entry, mode: 'ephemeral'|'sticky', pinned_commit, pin_verified, record_id, prompt }`; writes `agent_skills.bm-executor` in `.planning/config.json` + a record in `.planning/craft-skills/pins.json`

Release (Phase 16, unchanged): `bm-sdk query craft-skill.release --agent bm-executor --id <id>` -> `{ released: [record_id...], remaining }`; ephemeral only unless `--include-sticky`
