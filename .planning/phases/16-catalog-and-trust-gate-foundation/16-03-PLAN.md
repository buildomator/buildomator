Constants and helpers:

- `readPins(cwd)` -> parsed `{ version: 1, records: [] }` (missing file -> empty structure; parse error -> `error(..., ERROR_REASON.CONFIG_PARSE_FAILED)`). `writePins(cwd, pins)` -> mkdir -p the dir, write `pins.json.tmp` then `fs.renameSync` over `pins.json`, JSON with 2-space indent and a trailing newline.
- `parseFlags(args)` -> `{ positional: string[], flags: Record<string, string|boolean> }`: a token starting with `--` becomes a flag; it takes the next token as its value unless that token also starts with `--` or is absent (then `true`). Known flags: `--agent`, `--location`, `--id`, `--sticky`, `--approved`, `--include-sticky`, `--all`, `--catalog` (override path for tests).
- `loadCatalogViews(opts)` -> `{ cat, views }` where `cat = loadCraftSkillCatalog(opts.catalog || undefined)` and `views = deriveCatalogViews(cat)` so GSD_CRAFT_SKILL_CATALOG or `--catalog` fixtures work.
- `readFrontmatterName(skillMdPath)`: read the file, take only the first frontmatter block (between the first two lines that are exactly `---`), return the value of the first `name:` line trimmed, or null. This is the only read of the skill file and it stops at the frontmatter: the body is never parsed, returned or logged.
- `sha256File(p)` -> hex digest.
- `verifyLocalPin(skillDir, pinnedCommit)`: `spawnSync('git', ['-C', skillDir, 'rev-parse', 'HEAD'], { encoding: 'utf8', timeout: 5000 })`; if status 0 and stdout matches /^[0-9a-f]{40}/ -> `{ git: true, local_head, pin_verified: local_head === pinnedCommit }`; otherwise `{ git: false, local_head: null, pin_verified: false }`.
- `resolveLocation(cwd, config, location)` -> `{ ok, kind: 'path'|'global', entry, skillDir, skillMd, reason }`. Reject empty. If it starts with `global:`: the remainder must not contain `:` (reason "plugin-form skills carry no pin; use a project path or global:<name> checkout") and must match /^[a-zA-Z0-9_-]+$/; runtime = config.runtime || 'claude'; base = getGlobalSkillsBase(runtime) (null -> reject); skillDir = getGlobalSkillDir(runtime, name); skillMd must exist; accept when `validatePath(skillMd, base, { allowAbsolute: true }).safe` or when some root in `loadTrustedGlobalRoots(config)` passes the same check; otherwise reject with "resolves outside the runtime skills dir and outside agent_skills_security.trusted_global_roots". Else (project-relative): `validatePath(location, cwd)` must be safe (no absolute paths), `path.join(cwd, location, 'SKILL.md')` must exist; entry = location normalized to forward slashes without a leading `./`. These rules are the write-side mirror of buildAgentSkillsBlock so a stored entry is never one the reader would later refuse.
- `findApproval(pins, id, pinnedCommit)` -> first record with the same id and pinned_commit and a non-null approved_at, or null.

`insertCraftSkill(cwd, opts)` with `opts = { id, agent, location, sticky, approved, catalog }`:
1. Validate args (`id`, `agent`, `location` required; `error(usage, ERROR_REASON.USAGE)` otherwise). `agent = normalizeAgentName(agent)`.
2. `{ cat, views } = loadCatalogViews(opts)`; `entry = views.CRAFT_SKILLS_BY_ID[id]` or usage error "unknown catalog id".
3. `assessment = assessEntry(entry, cat)`; if `assessment.verdict === 'block'` -> `error('craft-skill insert refused: ' + renderAssessment(assessment), ERROR_REASON.SECURITY_SCAN_FAILED)` before touching anything.
4. `pins = readPins(cwd)`; `prior = findApproval(pins, id, entry.pinned_commit)`; if `!opts.approved && !prior` -> return `{ inserted: false, needs_approval: true, verdict: assessment.verdict, assessment, prompt: assessment.prompt }` (no writes). `approved_at = prior ? prior.approved_at : new Date().toISOString()`.
5. `config = loadConfig(cwd)`; `loc = resolveLocation(cwd, config, opts.location)`; if `!loc.ok` -> `error('craft-skill insert refused: ' + loc.reason, ERROR_REASON.SECURITY_SCAN_FAILED)`.
6. `name = readFrontmatterName(loc.skillMd)`; if `name !== entry.skill_name` -> error "craft-skill insert refused: skill-name-mismatch: SKILL.md declares <name>, catalog expects <skill_name>" (SECURITY_SCAN_FAILED).
7. `pin = verifyLocalPin(loc.skillDir, entry.pinned_commit)`; if `pin.git && !pin.pin_verified` -> error "craft-skill insert refused: pin-mismatch: checkout HEAD <local_head> differs from pinned commit <pinned_commit>" (SECURITY_SCAN_FAILED). `skill_md_sha256 = sha256File(loc.skillMd)`.
8. Append the pin record inside `withPlanningLock(cwd, ...)` and write pins: `{ record_id: id + '@' + agent + '@' + inserted_at, id, agent, mode: sticky ? 'sticky' : 'ephemeral', entry: loc.entry, source: entry.source, skill_path: entry.skill_path, pinned_commit: entry.pinned_commit, pin_verified: pin.pin_verified, local_head: pin.local_head, skill_md_sha256, license: entry.license, obligations: entry.obligations, trust_tier: entry.trust_tier, scripts_banned: assessment.scripts_banned, verdict: assessment.verdict, approved_at, inserted_at, released_at: null }` (exactly these 19 keys in this order; the SDK twin asserts the same order).
9. After the lock returns, write config (setConfigValue takes its own lock, so the two writes are sequential, never nested): `current = lookupByAgentName(config.agent_skills, agent)` normalized to an array; if it does not already include `loc.entry`, `setConfigValue(cwd, 'agent_skills.' + agent, [...current, loc.entry])`.
10. Return `{ inserted: true, id, agent, entry: loc.entry, mode, pinned_commit, pin_verified: pin.pin_verified, record_id, prompt: assessment.prompt }`.

`releaseCraftSkills(cwd, opts)` with `opts = { agent, id, includeSticky, all }`: require `agent` unless `all`. Select records with `released_at === null`, matching agent (normalized) unless all, matching id when given, and `mode === 'ephemeral'` unless `includeSticky` (an explicit `--id` plus `--include-sticky` is the only way to drop a sticky record). For each selected record: remove `record.entry` from the array at `agent_skills.<record.agent>` (via setConfigValue with the filtered array; write `[]` when it becomes empty), set `released_at` to now. Write pins. Return `{ released: [record_ids], remaining: count of still-active records }`.

`listCraftSkills(opts)` -> array of `{ id, domain, triggers, publisher, trust_tier, license, pinned_commit, target_agents, summary }` from the catalog views. `assessCraftSkill(opts)` -> `assessEntry(entry, cat)` for `opts.id` (usage error when unknown).

`module.exports = { PINS_RELATIVE_PATH, parseFlags, readPins, verifyLocalPin, resolveLocation, insertCraftSkill, releaseCraftSkills, listCraftSkills, assessCraftSkill, cmdCraftSkill }`.
